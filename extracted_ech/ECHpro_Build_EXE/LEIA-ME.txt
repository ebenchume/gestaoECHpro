COMO CRIAR O EXECUTÁVEL (obrigatório em PC Windows)
───────────────────────────────────────────────────

1. Copie ESTA PASTA INTEIRA para um computador com Windows 10/11.

2. Certifique-se de que tem o Python 3.10+ instalado:
   https://www.python.org/downloads/
   (Marque "Add Python to PATH" durante a instalação)

3. Faça DUPLO-CLIQUE no ficheiro:

      1_INSTALAR_E_GERAR_EXE.bat

4. Aguarde 1 a 3 minutos. No final, o executável estará em:

      dist\ECHpro.exe

5. (Opcional) Para criar um instalador profissional Setup.exe:
   - Instale o Inno Setup 6: https://jrsoftware.org/isinfo.php
   - Execute: 2_CRIAR_INSTALADOR.bat
   - O instalador sai em: dist_installer\ECHpro_Setup.exe

IMPORTANTE:
  Não é possível gerar um .exe Windows a partir de Linux/Mac
  de forma fiável. O .exe TEM de ser compilado num PC Windows.
